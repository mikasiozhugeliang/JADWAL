Cara Install sebagai APK di HP

Aplikasi ini dapat diinstal langsung ke HP Android Anda layaknya aplikasi asli (APK) tanpa perlu mengunduh dari Play Store:

Pengguna Android (Google Chrome):
  1. Buka halaman web aplikasi ini di browser Chrome HP Anda.
  2. Tekan tombol menu titik tiga () di pojok kanan atas browser.
  3. Pilih opsi "Tambahkan ke Layar Utama" atau "Install Aplikasi".
  4. Konfirmasi dengan menekan Install. Ikon aplikasi akan otomatis muncul di menu utama HP Anda!
Pengguna iPhone (Safari):
  1. Buka halaman ini lewat browser Safari.
  2. Ketuk ikon Bagikan (Share ) di bagian bawah.
  3. Pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
Tips Alarm: Pastikan izin suara diizinkan dan mode hening (silent) HP dimatikan agar alarm berbunyi tepat waktu!
